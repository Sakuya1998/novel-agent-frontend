# AI 协作工作流

## 规则优先级

用户当前请求高于仓库规则；`AGENTS.md` 高于本目录主题规则；主题规则高于个人偏好。无法确定需求、影响范围或安全边界时，先提出一个明确问题，不要猜测并扩大改动。

## 修改流程

1. 先检查相关源码、测试、脚本、配置和 Git 状态，识别现有模式。
2. 先写出简短的变更目标和验证计划，再进行最小修改。
3. 复用现有模块和工具函数；不要为了美化而重排无关文件。
4. 为行为变化添加测试；对配置变化运行解析、类型或构建检查。
5. 交付时列出改动文件、验证命令、结果和未解决风险。

## 安全边界

不要读取、输出或提交 `.env` 中的秘密；不要绕过权限、认证或 API 校验。删除文件、重写锁文件、批量格式化或升级依赖前，应先确认目标范围，并确保操作可恢复。生成文件必须从源契约或生成脚本产生。
