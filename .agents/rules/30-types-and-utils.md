# 类型与工具函数规范

## 类型

类型定义优先使用 `type` 表示联合、映射和派生类型，使用 `interface` 表示可扩展对象契约。领域类型放在对应特性；跨领域类型放在 `src/types.ts`，API 生成类型只从 `src/api/generated/` 导出。避免 `any`；无法避免时缩小范围并说明原因。

使用字面量联合、判别字段和泛型表达状态约束。不要用宽泛的 `string` 替代有限状态，也不要在组件中重复声明同一业务对象。公共函数的参数和返回值必须有显式、可读的类型。

## 工具函数

工具函数必须纯粹、单一职责、无隐藏副作用；优先放在使用它的领域目录，只有被至少两个独立领域复用时才提升到共享位置。函数命名使用动词开头，时间、URL、序列化和错误转换要覆盖边界输入并配套单元测试。

不要把 API 请求、React Hook 或 UI 状态塞进通用工具函数。优先复用已有实现，避免创建只有一处调用的抽象层。
